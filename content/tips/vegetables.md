채소는 고기보다 싸지만, **버리는 양은 제일 많은 식재료**예요. 잘 고르고 잘 보관하면 장보기 횟수도 줄고 음식물 쓰레기도 확 줄어요.

## 어떤 채소든 통하는 3가지

1. **무게감**: 같은 크기라면 들었을 때 묵직한 게 수분이 많고 싱싱해요.
2. **자른 단면**: 줄기나 꼭지의 자른 면이 마르거나 갈색으로 변하지 않은 것.
3. **색과 탄력**: 색이 선명하고, 살짝 눌렀을 때 단단하게 튕겨내는 것.

## 채소별 고르는 법

| 채소 | 이런 걸 고르세요 | 이런 건 피하세요 |
| --- | --- | --- |
| 상추·깻잎 | 잎이 선명하고 빳빳한 것 | 잎 끝이 누렇거나 물러진 것 |
| 시금치 | 잎이 짙은 초록, 뿌리 쪽이 붉은빛 | 잎이 축 늘어진 것 |
| 양배추 | 크기에 비해 묵직하고 겉잎이 초록 | 가볍거나 단면이 갈색인 것 |
| 브로콜리 | 봉오리가 빽빽하고 짙은 초록 | 봉오리가 노랗게 핀 것 |
| 오이 | 굵기가 고르고 가시가 뾰족 | 끝이 물렁한 것 |
| 애호박 | 표면에 윤기, 꼭지 단면이 싱싱 | 흠집이 많거나 물렁한 것 |
| 토마토 | 꼭지가 초록색으로 싱싱하고 단단 | 꼭지가 마르고 껍질이 쭈글한 것 |
| 당근 | 색이 진하고 표면이 매끈 | 잔뿌리가 많고 갈라진 것 |
| 감자 | 단단하고 매끈 | 싹이 났거나 초록빛이 도는 것 |
| 양파 | 겉껍질이 바삭하게 마르고 단단 | 윗부분이 물렁하거나 싹이 난 것 |
| 대파 | 흰 부분이 길고 단단, 잎이 선명 | 잎 끝이 누렇게 마른 것 |
| 버섯 | 갓이 도톰하고 물기 없이 단단 | 끈적이거나 갈색으로 변한 것 |

> **주의**
> 감자에 초록색으로 변한 부분이나 싹이 있으면 그 부분을 **넉넉히 도려내고** 드세요. 솔라닌이라는 성분이 있어서 많이 먹으면 탈이 날 수 있어요.

## 사 온 뒤가 더 중요해요: 보관법

### 냉장고에 넣을 것: 잎채소, 열매채소

잎채소의 가장 큰 적은 **물기**예요. 씻어서 넣으면 금방 물러요.

- 씻지 말고, **키친타월로 감싸** 지퍼백이나 밀폐용기에 넣으세요.
- 대파, 시금치, 아스파라거스처럼 길쭉한 채소는 **세워서** 보관하면 더 오래가요.
- 반 잘라 쓴 양배추, 무는 단면을 랩으로 딱 붙여 감싸세요.

### 상온에 둘 것: 감자, 양파, 고구마

- **서늘하고 어둡고 통풍이 잘 되는 곳**에 두세요. 신문지나 종이봉투가 좋아요.
- **감자와 양파는 따로** 두세요. 함께 두면 서로 빨리 상한다고 알려져 있어요.
- 고구마는 추위에 약해서 냉장고에 넣으면 오히려 금방 상해요.
- 토마토는 덜 익었으면 상온에서 익히고, 다 익은 건 냉장고에 넣어 며칠 안에 드세요.

### 얼려도 되는 것: 향신 채소

대파, 마늘, 청양고추는 **썰어서 냉동**해 두면 요리할 때 바로 한 줌씩 쓸 수 있어요. 버섯도 손질해서 얼리면 찌개나 볶음에 그대로 쓸 수 있고요. 자세한 냉동 요령은 [냉동실 200% 활용법](../freezer/)에 있어요.

## 온라인으로 채소 살 때

- 잎채소는 **적게 자주**, 감자·양파 같은 뿌리채소는 **넉넉히** 사세요.
- 도착하면 바로 상자에서 꺼내 상태를 확인하세요. 신선식품은 문제가 있을 때 **사진이 있어야** 교환이나 환불이 수월해요.
- 제철 채소가 맛도 좋고 값도 착해요. [계절별 제철 장보기 달력](../seasonal/)을 참고하세요.

> **한 줄 요약**
> 고를 땐 **묵직하고 단면이 싱싱한 것**, 보관할 땐 **물기는 빼고 종류별로 따로**.
