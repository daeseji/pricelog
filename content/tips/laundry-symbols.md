옷을 빨았더니 줄어들거나 색이 빠진 적 있나요? 옷 안쪽 라벨의 **세탁 기호**만 확인해도 대부분 막을 수 있어요.

> **참고**
> 세탁 기호는 나라와 제품에 따라 **모양이 조금씩 달라요.** 아래는 자주 보는 기호의 일반적인 뜻이에요. 그림 옆에 글로 설명이 있다면 그걸 따르세요.

## 물세탁

| 기호 | 뜻 |
| --- | --- |
| 물이 담긴 **대야** | 물세탁 가능. 안의 숫자는 **최고 물 온도**(예: 30, 40) |
| 대야 안에 **손** | **손세탁**만 |
| 대야에 **X** | 물세탁 안 됨 |
| 대야 아래 **밑줄** | 약하게 세탁 (섬세 코스) |

## 표백

| 기호 | 뜻 |
| --- | --- |
| **삼각형** | 표백 가능 |
| 삼각형에 **빗금** | 산소계 표백제만 |
| 삼각형에 **X** | 표백 안 됨 |

## 다림질

| 기호 | 뜻 |
| --- | --- |
| **다리미** 안에 점 1개 | 낮은 온도 |
| 점 2개 | 중간 온도 |
| 점 3개 | 높은 온도 |
| 다리미에 **X** | 다림질 안 됨 |

## 드라이클리닝과 건조

| 기호 | 뜻 |
| --- | --- |
| **동그라미** | 드라이클리닝 가능 |
| 동그라미에 **X** | 드라이클리닝 안 됨 |
| **옷걸이·네모** 그림 | 건조 방법 (걸어서, 뉘어서, 그늘에서 등) |
| 네모 안의 **동그라미** | 기계(텀블) 건조 관련 |

## 헷갈릴 땐 이 순서로

1. **물세탁 가능?** → 온도 확인
2. **손세탁만?** → 미지근한 물에 조물조물
3. **표백 가능?** → 산소계만인지 확인
4. **건조 방법** → 걸기 / 뉘어 말리기 / 그늘
5. 확신이 없으면 **찬물 + 섬세 코스 + 그늘 건조**가 가장 안전해요.

## 자주 망치는 옷

- **니트·울**: 뜨거운 물과 건조기에 줄어들기 쉬워요. **뉘어서** 말리세요.
- **청바지**: 뒤집어서 찬물에 빨면 색 빠짐이 줄어요.
- **흰 옷**: 색깔 옷과 따로 빨아요.
- **기능성 의류**: 섬유유연제를 피하세요. [섬유유연제 제대로 쓰기](../fabric-softener/)를 참고하세요.

> **한 줄 요약**
> **대야(물세탁)·삼각형(표백)·다리미(온도)·동그라미(드라이)**, 모르겠으면 **찬물 + 섬세 + 그늘**.
