**PB(Private Brand) 상품**은 마트나 쇼핑몰이 자기 이름을 붙여 파는 상품이에요. 쿠팡의 곰곰·탐사, 대형마트의 자체 브랜드 같은 것들이요. 광고비와 유통 단계가 줄어서 **같은 품질에 더 싼** 경우가 많아요.

## PB 상품은 누가 만들까?

대부분 **전문 제조사가 만들고** 유통사는 이름을 붙여 팔아요. 그래서 포장 뒷면의 **'제조원'**을 보면 어느 회사가 만들었는지 알 수 있어요.

> **팁**
> 제조원을 보면 **유명 브랜드 제품을 만드는 회사**가 PB도 만드는 경우가 있어요. 이럴 땐 품질 차이가 크지 않을 가능성이 높아요.

## PB가 잘 맞는 품목

| 품목 | 이유 |
| --- | --- |
| 생수 | 수원지와 수질 기준이 같다면 차이가 적음 |
| 우유·계란 | 등급 표시로 품질 확인 가능 |
| 휴지·키친타월 | 겹수, 길이로 비교 가능 |
| 세제·주방세제 | 성분과 용량으로 비교 가능 |
| 냉동 채소·과일 | 원산지와 상태로 비교 |
| 기본 양념 | 식품 유형과 원재료로 비교 |

## 브랜드 제품이 나을 수 있는 경우

- **맛과 향이 중요한 것**: 커피, 과자, 라면처럼 취향이 뚜렷한 품목
- **특정 기능이 중요한 것**: 샴푸, 화장품처럼 성분 조합이 다른 것
- **익숙한 맛이 필요한 것**: 아이 간식, 특정 소스

이런 건 PB를 **작은 용량으로 먼저** 사서 맛보고 결정하세요.

## PB 비교 체크리스트

- [ ] **제조원**이 어디인지
- [ ] **원재료·성분**이 브랜드 제품과 비슷한지
- [ ] **용량**이 같은지 (단위 가격으로 비교)
- [ ] **리뷰**에서 반복되는 불만이 있는지
- [ ] 나에게 중요한 **맛·기능**이 있는지

단위 가격 비교는 [진짜 싼 건 '100g당 가격'이 알려줘요](../unit-price/)에 정리했어요.

> **한 줄 요약**
> PB는 **제조원**을 보고, **생수·휴지·세제·우유**부터 바꿔보세요.
