"이번 달엔 식비를 아껴야지" 다짐만으로는 잘 안 줄어요. **숫자로 된 예산**이 있어야 줄일 수 있어요. 어렵지 않아요. 지난 지출만 보면 돼요.

## 1단계: 지난 3개월 식비 모으기

- 카드 명세서와 가계부 앱에서 **장보기, 외식, 배달, 카페**를 따로 모아요.
- 3개월 **평균**을 내요. 한 달만 보면 명절이나 모임 때문에 들쭉날쭉해요.

| 항목 | 1월 | 2월 | 3월 | 평균 |
| --- | --- | --- | --- | --- |
| 장보기 | | | | |
| 외식·배달 | | | | |
| 카페·간식 | | | | |

## 2단계: 목표는 평균의 90%부터

처음부터 크게 줄이면 금방 포기하게 돼요. **평균의 90%**를 첫 목표로 잡고, 성공하면 조금씩 낮춰요.

## 3단계: 월 예산을 주 단위로 나누기

- 월 예산을 **4.3으로 나누면** 주간 예산이 나와요.
- 한 달 단위로 관리하면 월말에 몰아서 부족해지기 쉬워요. **주 단위**로 보면 조절이 쉬워요.
- 남은 돈은 다음 주로 넘기거나, **작은 보상**으로 써도 좋아요.

## 가장 효과가 큰 곳부터

| 줄이기 쉬운 곳 | 방법 |
| --- | --- |
| 배달 | 주 1회로 정하고, 나머지는 냉동 간편식으로 |
| 버리는 음식 | 소분 냉동, 냉장고 파먹기 |
| 편의점 간식 | 대용량으로 사서 소분 |
| 카페 | 집에서 내려 가져가기 |

버리는 음식 줄이는 법은 [음식물 쓰레기 줄이는 법](../food-waste-reduce/)에 있어요.

## 장보기 예산 지키는 요령

- **장보기 목록**을 쓰고 목록에 있는 것만 사요. [장보기 목록 쓰는 법](../shopping-list/)을 참고하세요.
- 온라인 장바구니에 담은 뒤 **예산을 넘으면 우선순위가 낮은 것부터** 빼요.
- 자주 사는 물건은 **싼 날 사두면** 같은 예산으로 더 많이 살 수 있어요.

> **팁**
> 식비를 무리하게 줄이면 결국 외식이나 배달로 보상하게 돼요. **잘 먹으면서 버리는 것만 줄이는 게** 가장 오래가는 절약이에요.

> **한 줄 요약**
> **지난 3개월 평균 → 90% 목표 → 주 단위 관리.**
