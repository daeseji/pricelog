# 싸다구 제휴 링크 서버

'내 상품'에 방문자가 직접 담은 쿠팡 상품을, 방문자가 **'쿠팡에서 보기'를 누른 순간에만** 싸다구의 쿠팡 파트너스 링크로 바꿔 주는 작은 서버예요.

'매일 확인' 신청도 이 서버가 받아요. 상품 번호, 옵션 번호, 판매 옵션 번호, 쿠팡 상품 이름만 스크립트 속성에 모아 두고(`POOL_N`, `POOL_0`...), GitHub Actions가 `?action=pool`로 목록을 받아 가격을 확인해요. 코드를 고친 뒤에는 '배포 > 배포 관리 > 수정(연필) > 버전: 새 버전 > 배포'로 같은 웹 앱 주소에 새 버전을 올려요.

## 왜 서버가 필요한가요

- 아무 상품이나 제휴 링크로 바꾸려면 쿠팡 파트너스 딥링크 API를 비밀 키로 불러야 해요.
- 비밀 키를 웹페이지 코드에 넣으면 누구나 볼 수 있고, 쿠팡 운영정책도 키를 남과 공유하는 걸 금지해요. 그래서 키를 숨겨 둘 서버가 따로 필요해요.
- 싸다구가 있는 GitHub Pages는 서버 코드를 실행하지 못하고, Vercel 무료(Hobby) 플랜은 제휴 링크가 목적인 사용을 상업적 이용으로 보고 허용하지 않아요.

그래서 무료로 쓸 수 있는 두 가지를 준비해 두었어요. 지금은 가입이 필요 없는 **Google Apps Script**를 써요.

| 파일 | 어디에 올리나요 | 비고 |
|---|---|---|
| `apps-script.gs` | Google Apps Script 웹 앱 (지금 쓰는 것) | 구글 계정만 있으면 돼요 |
| `link.js` | Cloudflare Workers | 나중에 옮기고 싶을 때. 다른 사이트에서 오는 요청까지 막을 수 있어요 |

## Apps Script 설정 (한 번만)

코드는 Apps Script 프로젝트 **'싸다구 제휴 링크 서버'**에 이미 들어 있어요. 남은 일은 두 가지예요.

1. **키 넣기**: 프로젝트 설정(톱니바퀴) > 스크립트 속성 > '스크립트 속성 추가'를 두 번 눌러 아래처럼 넣고 저장해요. 값은 쿠팡 파트너스 > 추가 기능 > 파트너스 API 화면의 '복사' 버튼으로 가져와요.
   - `COUPANG_ACCESS_KEY` : Access Key
   - `COUPANG_SECRET_KEY` : Secret Key
2. **배포**: 오른쪽 위 '배포' > '새 배포' > 유형 선택(톱니바퀴)에서 '웹 앱'을 고르고, 실행 사용자는 '나', 액세스 권한은 '모든 사용자'로 정한 뒤 '배포'를 눌러요.
   - '액세스 승인'을 누르고 구글 계정을 고르면 "Google에서 확인하지 않은 앱"이라는 화면이 나와요. 내가 만든 스크립트라서 그래요. '고급' > '싸다구 제휴 링크 서버(으)로 이동'을 누르고 '허용'을 눌러요. 이 스크립트가 받는 권한은 '외부 서비스에 연결'(쿠팡 API 호출) 하나예요.
   - 마지막 화면의 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 `assets/mine.js`의 `LINK_API`에 넣고 `python3 scripts/build_site.py`로 다시 만들어요.

키를 바꾸거나 지워도 다시 배포할 필요는 없어요. 서버를 멈추고 싶으면 '배포 관리'에서 그 배포를 보관 처리하거나, `LINK_API`를 다시 빈칸으로 두면 돼요. 그러면 '내 상품'은 수수료 없는 일반 쿠팡 주소로 열려요.

## 쿠팡 파트너스 정책을 지키는 장치

쿠팡 파트너스 운영정책과 이용약관(2026-11 확인)에서 문제가 될 수 있는 행동을 하나씩 막아 두었어요.

| 정책에서 금지하는 것 | 싸다구에서 막은 방법 |
|---|---|
| 자동·강제 이동, 백그라운드 호출 | 쿠팡은 방문자가 버튼을 누를 때만 열려요. 링크 생성도 누른 순간에만 하고, 쿠팡 페이지를 미리 불러오지 않아요 |
| 로봇·자동화 도구로 생기는 무효 클릭 | `go.html`은 검색 로봇, 링크 미리보기, 자동화 도구에는 쿠팡으로 넘기지 않아요. 서버는 줄인 주소(coupa.ng, link.coupang.com/a/...)를 대신 열지 않아요 |
| 오클릭을 부르는 버튼 배치 | '쿠팡에서 보기'는 카드 맨 아래 구분선 아래에 혼자 두었어요 |
| 클릭 유도 문구, 보상 제공 | 버튼은 '쿠팡에서 보기'뿐이고, 보상이나 할인 미끼가 없어요 |
| API 키 공유·노출 | 키는 서버의 스크립트 속성에만 있고 페이지 코드에는 없어요 |
| 비정상 API 호출 | 새 링크는 전체 합쳐 시간당 20개, 하루 150개까지만 만들어요. 쿠팡이 오류를 주면 한 시간 동안 멈춰요. 링크 생성은 POST 요청으로만 해요 |
| 본인·가족 구매로 수익 발생 | 사이트 곳곳에 '제휴 링크 끄기' 스위치를 두었어요. 운영자와 가족의 브라우저에서는 켜 두세요. 주소 뒤에 `?noaff=1`을 붙여 한 번 열어도 켜져요 |

운영자가 직접 지켜야 할 것도 있어요.

- 싸다구 주소(`https://daeseji.github.io/pricelog/`)가 쿠팡 파트너스 '내 정보'의 미디어 목록에 등록돼 있어야 해요. 등록되지 않은 매체에 링크를 노출하면 이용 제한 사유예요.
- 내 링크를 반복해서 누르지 않아요. 지인에게 사이트를 소개하는 건 괜찮지만, "이 링크로 사 줘"처럼 클릭이나 구매를 부탁하는 메시지는 보내지 않아요.
- 클릭수, 전환율, 수익금 같은 리포트 화면 숫자는 공개하지 않아요.
